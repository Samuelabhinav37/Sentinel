# Security Policy

## Reporting

Use [GitHub private vulnerability reporting](https://github.com/Samuelabhinav37/Sentinel/security/advisories/new). Do not open a public issue for an unpatched vulnerability.

Reports should include the affected component, deployment assumptions, reproduction steps, potential blast radius, and suggested containment if known.

## Priority areas

- Authentication or authorization bypasses
- Unsafe automated-response execution
- Forged, replayed, or mismatched alert actions
- Exposure of SIEM, SOAR, model-provider, or infrastructure credentials
- Detection pipeline tampering or evidence-integrity failures
- Network exposure beyond documented trust boundaries

Sentinel is a lab/reference project. Its presence in this repository does not authorize testing against systems or accounts you do not own.
